# opencode (motor de modelos do Gota Desktop 2)

`opencode.zip` traz o `opencode.exe` (MIT, https://github.com/sst/opencode; 1.19.1). O Gota extrai o `.exe` aqui na primeira execução, sem baixar nada. O `.exe` (172 MB) fica fora do git.
Para atualizar: `winget install SST.opencode`, compacte o `opencode.exe` do pacote em `opencode.zip` e substitua este arquivo.
