# opencode (motor de modelos do Gota Desktop 2)

Coloque aqui `opencode.exe` (MIT, https://github.com/sst/opencode). O Gota usa esta cópia, dentro do projeto, e não baixa nada durante o uso.
O arquivo tem 172 MB e não vai para o git (limite de 100 MB do GitHub); `build.bat` o empacota no Gota.exe.
Para obter: `winget install SST.opencode` e copie o `opencode.exe` do pacote para esta pasta.
